# Notification System

A backend notification service built with Django and Django REST Framework.

## Features

- Trigger-based notifications
- Email notifications
- WhatsApp notifications
- Web Push notifications
- JWT Authentication
- REST APIs
- PostgreSQL

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT
- Postmark
- WhatsApp Cloud API
- OneSignal
